# Landed-work audit, batch 10 (forge, tasks 615-625)

This audit checks each task's landed change against its own text. Nine of
the ten landed commits are `Merge main into …` merges, so their own change
was read as `git diff <landed>^2 <landed>`. The one non-merge landing
(a4c364b, task 620) was read as `git diff <base> <landed>`. Each change
was then traced on the current tree (96d5841). Several pieces have moved
since landing: queue answering is now in `src/queue/answer.rs` (7060117),
the CLI verbs are under `src/cli/`, and `portal_doc` is in
`src/view/projects.rs`. Some task texts were truncated in the brief this
audit was given, and the task record could not be read from here: `forge
show` has no store in this clone. Those tasks were judged on the visible
text, plus what the landed change and its tests show about the rest.

Only the tests each task named, or their current successors, were run.
All of them ran on 2026-09-28 against this tree, with `bwrap` present at
`/usr/bin/bwrap`, so the sandboxed e2e tests really ran. Every test run
passed. Task 617 is not in this batch's task list.
