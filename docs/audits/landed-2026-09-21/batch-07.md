merges (560, 561, 562, 563, 564, 572); their own change is `git diff
<landed>^2 <landed>`, equivalently the first-parent history from each
task's stated base to the merge's second parent. 566, 568, 569 and 571
land directly (single-parent commits), so their own change is `git diff
<base> <landed>`. Task 565, 567 and 570 are not in this batch's task
list and are not audited here.

All ten landed commits are ancestors of the current tree
(`27b7b29`), and every piece traced below is still in place under the
same names the landed commits gave it — nothing in this batch has moved
or been superseded by a later task. Only the tests each task named (or
implied) were run (`cargo test --locked <name>` against the appropriate
package, not the full suite), on 2026-10-03 against this tree; all of
them passed. `cargo test --locked --test naming`, `--test boundary` and
`every_doc_is_indexed_and_the_index_names_only_real_files` (the docs
index test) were also run and pass.
